# Account Recovery

If you are locked out of your Chungus Bank account, we can help you regain access.

## Steps
1. Confirm the name and ZIP code on the account.
2. Send a one-time passcode (OTP) to the phone on file and have the customer read it back.
3. Reset the sign-in once the OTP is confirmed.
